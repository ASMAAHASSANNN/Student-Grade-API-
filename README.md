# Student Grades API

A simple REST API built with FastAPI for storing and retrieving student grades.

## Features
- Add a grade for a student
- Get all grades for a student
- Get the average grade for a student
- Input validation
- Error handling

## Requirements
- Python 3.10 or later recommended
